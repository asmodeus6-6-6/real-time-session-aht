Tips & Tricks

Practical ways to use the tracker.

  1. Paste the latest report into Live Input.
  2. Set the AHT target before reviewing performance.
  3. Use Agent Analysis for individuals and TL / AM / Process for groups.
  4. Use Copy Image when sharing results.
  5. Admins should publish the weekly Agent Details master before analysis.
